# RMC Gestión

Aplicación web/PWA para gestión de cobros, gastos e IVA de RMC Climatización.

- Ingresos y gastos
- IVA 21 %, 10 %, 4 %, 0 % o personalizado
- Transferencia, tarjeta, efectivo u otro
- Panel de resultado e IVA
- Acceso privado mediante Supabase Auth
- Datos sincronizados mediante Supabase Realtime

Los movimientos están protegidos mediante Row Level Security (RLS) y asociados al usuario autenticado.
